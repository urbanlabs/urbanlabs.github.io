UrbanLabs helped initiate and continue work on the Mobility Data Interoperability Principles, a collaboratively developed effort to define what interoperability in mobility should mean in practice.

The project brings together public- and private-sector participants around a shared direction: clearer expectations, more useful coordination, and a better foundation for systems that need to work together rather than in isolation.

For UrbanLabs, this work matters because it connects technical standards to institutional trust. It is one thing to build a tool or a data feed; it is another to help create a shared language that makes whole ecosystems function better.
